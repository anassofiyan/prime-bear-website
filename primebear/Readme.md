# Prime Bear Website

A modern, responsive business website for **Prime Bear**, showcasing bakery consulting and creative business services. The website is designed with a clean user interface, smooth user experience, and mobile-first responsiveness.

## Features

- Responsive design for all devices
- Modern landing page
- Services section
- About Founder page
- Contact page
- Book Consultation form
- Google Sheets integration for booking requests
- Email notifications for new consultation requests
- Fast and optimized performance
- SEO-friendly structure

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/primebear-website.git
```

Navigate into the project

```bash
cd primebear-website
```

If using npm

```bash
npm install
```

Start the development server

```bash
npm run dev
```

## Deployment

The website is deployed using **Netlify**.

Continuous deployment is enabled through GitHub.
